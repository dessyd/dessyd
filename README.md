# Hi, I'm Dominique 👋

Engineer based in Brussels. I build with Python, Arduino and AI agents, and I explore Splunk and the Model Context Protocol (MCP).

## What I'm working on

- **Splunk and MCP**: [splunk-mcp](https://github.com/dd-Splunk/splunk-mcp) is a local proof of concept that runs Splunk Enterprise and the Splunk MCP server in Docker (community project, not official).
- **Agent-based workflows**: [News-Aggregator](https://github.com/dessyd/News-Aggregator) builds a daily press review from RSS feeds, summarised by an LLM and published on GitHub Pages.
- **Arduino and IoT**: sensors, MQTT and secure device provisioning, mostly in private repositories for now.
- **Small tools**: Bash utilities such as [restic-backup](https://github.com/dessyd/restic-backup) for S3-compatible backups.
